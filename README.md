# TradeX Ai Pro — Native Android Overlay APK

Native Android Floating Overlay & Real-Time Screen Analysis APK project with GitHub Actions auto-build.

## How to Build the APK on GitHub
1. Extract this ZIP file (`TradeX-AI-Pro-Native-APK.zip`).
2. Upload all extracted files and folders to your GitHub repository.
3. Open the **Actions** tab on GitHub -> click **Build Android APK** -> wait ~1 minute until the green checkmark (`✓`) appears.
4. Scroll down to **Artifacts** and download **`TradeX-AI-Pro-APK`** to get **`TradeX-AI-Pro.apk`**.
